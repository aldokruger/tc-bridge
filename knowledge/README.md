# Conhecimento Teamcenter

Diretorio de conhecimento versionado localmente (plano, secao 6.4).

## Estrutura

- `catalog/` — padroes aprovados para diagnostico, queries, workflows e customizacoes
- `runbooks/` — procedimentos operacionais revisados
- `examples/` — exemplos homologados de queries, workflows, BMIDE, ITK, SOA e AWC
- `schemas/` — schemas JSON consumidos pelo runtime

## Regras

1. JSON para registros processados pelo runtime; Markdown para conteudo humano.
2. Nenhum conteudo Siemens licenciado e copiado integralmente; apenas referencias e resumos permitidos.
3. Promocao do qmd para o catalogo exige revisao humana e registro de hash, autor, data e releases.
4. Divergencia de release reduz a confianca ou bloqueia a geracao.
